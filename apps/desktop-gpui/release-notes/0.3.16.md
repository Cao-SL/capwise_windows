## 中文

- 区域录制用边框标记范围，录制区外保持原亮度。
- AI 字幕优化显示校对和断句的实际进度。云端 API 可并行处理多批，每批附带临近字幕和术语，校对超时时保留原字幕。
- 在侧栏、画布或「编辑全部字幕」输入和删除文字时，编辑框先更新，停顿后再提交。文字修改尽量只重算对应的字幕片段，减少输入间的预览重绘。

## English

- Area recording marks the capture boundary with an outline and keeps the rest of the screen at its original brightness.
- AI subtitle optimization shows progress for proofreading and line breaks. Cloud APIs can process several batches in parallel, with neighboring subtitles and glossary terms in each request. A proofreading timeout preserves the originals.
- Caption fields in the sidebar, canvas, and full caption editor update while you type and commit after a pause. Text edits reproject the affected caption fragments where possible and reduce preview redraws between keystrokes.
