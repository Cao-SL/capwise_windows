## 中文

- 豆包语音新增流式识别 2.0，提供小时版和并发版。连接测试和字幕生成使用所选资源，已有权限的用户可继续使用极速版。
- 本地 Qwen 字幕识别直连本机服务，避免系统代理拦截健康检查和转写请求。
- 修复 Studio 的消息队列满时无法停止录制的问题。
- MP4 自定义导出的每像素比特数上限提高到 1.0，软件编码在高质量设置下可保留更多细节。
- Windows 在打开录制目标选择器时才开始采集缩略图。部分旧显卡上的启动崩溃仍在排查。

## English

- Doubao Speech adds Streaming ASR 2.0 with hourly and concurrency plans. Connection tests and caption generation use the selected resource. Flash recognition remains available to accounts with existing access.
- Local Qwen caption generation connects directly to its on-device service so system proxies cannot intercept its health checks or transcription requests.
- Fixed a Studio recording stop deadlock when the recorder's message queue is full.
- Custom MP4 export now supports up to 1.0 bits per pixel. Software encoding can preserve more detail at higher quality settings.
- Windows now captures thumbnails when you open the recording target picker. A startup crash on some older GPUs is still under investigation.
